# ⚡ Quick Start Guide

Panduan cepat untuk menggunakan README profile GitHub Anda.

## 🚀 Langkah-Langkah Cepat

### 1️⃣ Push ke GitHub (WAJIB)
```bash
git add .
git commit -m "✨ Update advanced GitHub profile README"
git push origin main
```

### 2️⃣ Enable GitHub Actions
1. Buka repository di GitHub
2. Klik tab **Actions**
3. Klik **"I understand my workflows, go ahead and enable them"**

### 3️⃣ Set Permissions
1. **Settings** → **Actions** → **General**
2. **Workflow permissions** → Pilih **"Read and write permissions"**
3. Centang **"Allow GitHub Actions to create and approve pull requests"**
4. **Save**

### 4️⃣ Manual Trigger (Test)
1. Tab **Actions** → Pilih **"Generate Snake Animation"**
2. **Run workflow** → **Run workflow**
3. Tunggu selesai (±1-2 menit)

## 🐛 Troubleshooting Cepat

### Snake Animation tidak muncul?
```bash

# Actions → Generate Snake Animation → Run workflow
```
Tunggu 2-3 menit, refresh halaman profile

### Stats tidak muncul?
- Pastikan username benar: `tetraxion`
- Coba clear cache browser (Ctrl + F5)
- Tunggu beberapa menit

### Workflow gagal?
1. Cek tab Actions untuk error message
2. Pastikan permissions sudah di-set
3. Coba run ulang workflow
